# Contributing

ggbrick is public so that it can be read, forked and used under the [MIT License](LICENSE). It does not take outside contributions yet.

## Why not yet

The catalog is at version 0.x and grows wave by wave. Each component goes through review gates (contract, implementation, Figma parity, documentation) whose approvals are recorded in the repository, and the Figma library is maintained alongside the code. A change that arrives outside that process cannot be approved the same way, so for now:

- issues are not tracked for outside requests;
- pull requests from forks are closed without review.

This file will describe how to contribute when that changes.

## What you can do

- Use the code under the terms of the license. The components are made to be copied: see [packages/svelte/README.md](packages/svelte/README.md).
- Fork the repository and adapt it. `README.md` lists the commands; `AGENTS.md` and `authoring/` describe how the system is authored.
- Report a security problem privately: see [SECURITY.md](SECURITY.md).
