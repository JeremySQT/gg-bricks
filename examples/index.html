ggbrick review examples

Each page is an interactive review of one component across brands, appearances and densities. Add a list item when you add examples/<id>/index.html.

  • Foundations: palette, surfaces, typography, spacing, elevation, motion and brands
  • Overlay spike: top-layer popovers and dialogs from themed subtrees, nested, clipped containers, anchor positioning (pre-wave 3)
  • Button: intents, appearances, sizes, slots, states, forms, links and difficult cases
  • ButtonGroup: sizes, orientations, alignment, wrap and stack, dialog footers
  • Icon: sizes, decorative or named, inline with text, inside buttons, other grids
  • Counter: values, overflow, sizes, next to text and inside buttons
  • Shortcut: notation, platforms, plain and keycap appearances, inside buttons
  • IconButton: intents, appearances, sizes, states, links, beside Buttons, toolbars
  • Link: destinations, file formats, links in text, wrapping, tone inherit, translated suffixes
  • Badge: intents, appearances, sizes, leading icons, tables, truncation, beside a Counter
  • Field: label, description, required marker, error message, every control, a form section
  • InputText: types, sizes beside Buttons, conditions, icons, trailing actions, difficult cases
  • NumberInput: sizes beside InputText, conditions, bounds and steps, locales, form submission, difficult cases
  • Textarea: sizes beside InputText, resize vertical, auto and none, conditions
  • Checkbox: selections and conditions, descriptions, select all, table rows, a required acceptance
  • Switch: positions and conditions, settings lists, hidden labels
  • RadioGroup and Radio: keyboard, orientations, conditions, descriptions, a required question
  • CheckboxGroup: orientations, sizes, conditions, a required question, select all outside the group
  • Spinner: sizes, inherited color on surfaces and actions, named status, turn speed
  • Progress: values, intents, sizes, indeterminate, hidden label, long labels
  • Skeleton: text lines beside real text, blocks, circles, a card loading
  • Alert: intents, title and content, actions, dismiss, live announcements, long messages
  • Toast: intents, actions, countdown and pause, max and queue, placements, over a dialog
  • Tooltip: icon buttons, sides, a disabled control, dark subtree and clipping
  • Popover: filters, a short form, nested popovers, focus, dark subtree and clipping
  • Dialog: sizes, alert dialog, explicit choice, scrolling body, nested, dark subtree
  • Menu: icons, shortcuts, groups, danger and disabled items, links, scrolling, typeahead
  • Select: sizes, groups, disabled options, a long list, typeahead, readonly, dark subtree
  • Combobox: filtering with accents, groups, a server search, empty result, readonly
  • Tabs: sizes, vertical, manual activation, a disabled tab, counters, overflow, RTL
  • Toolbar: tooltips, a menu, a popover, separators, a disabled item, sizes, wrapping
  • Accordion: single and multiple, heading levels, a disabled item, nested, long headings
  • Breadcrumb: sizes, separators, a home icon, collapse into a menu, truncation, RTL
  • Pagination: constant item count, bounds, siblings, sizes, links, RTL
  • Avatar: sizes, shapes, pictures, initials (accents, scripts, emoji), failed pictures, in context
  • AvatarGroup: max, total, +N, sizes, shapes, stacking, ring on other surfaces
  • DataField: orientations, sizes, empty values, rich values, a details panel, stacking in a narrow column
  • Divider: horizontal, vertical, labeled breaks, in rows and running text
  • Table: sizes, column lines, rich cells, row actions, footer, empty, inline scroll, sticky header, RTL
