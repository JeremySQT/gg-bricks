ggbrick review examples

Each page is an interactive review of one component across brands, appearances and densities. Add a list item when you add examples/<id>/index.html.

  • Foundations: palette, surfaces, typography, spacing, elevation, motion and brands
  • Overlay spike: top-layer popovers and dialogs from themed subtrees, nested, clipped containers, anchor positioning (pre-wave 3)
  • Button: intents, appearances, sizes, slots, states, forms, links and difficult cases
  • ButtonGroup: sizes, orientations, alignment, wrap and stack, dialog footers
  • Icon: sizes, decorative or named, inline with text, inside buttons, other grids
  • Counter: values, overflow, sizes, next to text and inside buttons
  • Shortcut: notation, platforms, plain and keycap appearances, inside buttons
  • IconButton: intents, appearances, sizes, states, links, beside Buttons, toolbars
  • Link: destinations, file formats, links in text, wrapping, tone inherit, translated suffixes
  • Badge: intents, appearances, sizes, leading icons, tables, truncation, beside a Counter
  • Field: label, description, required marker, error message, every control, a form section
  • InputText: types, sizes beside Buttons, conditions, icons, trailing actions, difficult cases
  • Textarea: sizes beside InputText, resize vertical, auto and none, conditions
  • Checkbox: selections and conditions, descriptions, select all, table rows, a required acceptance
  • Switch: positions and conditions, settings lists, hidden labels
  • RadioGroup and Radio: keyboard, orientations, conditions, descriptions, a required question
  • CheckboxGroup: orientations, sizes, conditions, a required question, select all outside the group
