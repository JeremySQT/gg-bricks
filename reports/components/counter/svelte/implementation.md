# Counter — Svelte implementation report

Component: `packages/svelte/src/components/counter/` (Svelte 5.57.1; no Bits UI primitive: a counter is static content with no native semantics to borrow). Review page: `examples/counter/`; self-contained preview: `dist/previews/counter.html` (`npm run build:preview counter`). Implemented on 2026-10-14 against contract digest `780d5bb9…` (approved at the grouped contract gate of 2026-10-14); implementation approval pending (grouped implementation gate with Icon and Shortcut).

## Structure

- `Counter.svelte`: one `<span class="ggb-counter" data-size data-overflow?>` root, which is the container part (no separate target layer: the counter is not interactive), holding `ggb-counter__value` (the digits) and, when `label` is set, a visually hidden `ggb-counter__label` that starts with a space so that the accessible text reads as one phrase (`8 unread messages`). No role, no `aria-*`, no `tabindex`: the visible text stays the text and the host decides whether the counter is announced (Button hides its trailing content). Native attributes pass through; `class` is merged; `ref` is bindable.
- `types.ts`: `CounterProps` extends the native span attributes minus `children`, `role` and `tabindex`; `value`, `max`, `size`, `label`, `ref`.
- `counter.css`: structure only (`inline-grid`, line-box height, `min-inline-size: 1lh`, `flex: none`, inline padding, inset `box-shadow` in `currentColor`, tabular figures, forced colors). Every dimension and the typography come from `tokens.generated.css`.
- `contract.generated.ts`, `tokens.generated.css`: generated by `npm run build:svelte` (`--ggb-counter-typography` plus the `-letterSpacing` and `-fontFeatureSettings` helpers per size, `--ggb-counter-radius`, `--ggb-counter-borderWidth`, `--ggb-counter-paddingInline`).
- Value formatting: `Math.floor`, clamp at 0, then `Intl.NumberFormat(undefined, { maximumFractionDigits: 0 })` (digit grouping follows the environment's locale once `max` is raised above 999); overflow appends `+` to the formatted `max`. A non-finite `value` shows 0; a non-finite `max` falls back to 99; `max` is floored and kept at least 1.

## Test adjustments made while implementing (new tests, before their first pass)

- Geometry: the first draft asserted that a single digit is always square (width = line box). The contract only sets a minimum: at comfortable density the inline padding (6 px per side) plus the digit already exceeds the 15.4 px sm line box, so the box is 19.1 × 15.4 px. The assertion now checks the literal rule, width = max(line box, digit + 2 × padding), and still asserts the square wherever the padding allows it (compact and standard). The code was right; the new assertion is the contract's, neither weaker nor stronger than the rule.
- Geometry and computed values: `min-inline-size: 1lh` computes to 15.3906 px (Chromium resolves `lh` in 1/64 px layout units), not the decimal 15.4. The assertion compares the minimum with the element's laid-out block size at 0.005 px, which is the rule (minimum width equals the height), and with the token line box at 0.05 px.
- Forced colors: the transparent background computes as `rgba(255, 255, 255, 0)` (forced to Canvas, alpha kept); the assertion checks alpha 0 instead of the literal black.
- Two code fixes found by the tests: `flex: none` on the root (an explicit `min-inline-size` replaces the automatic content floor of a flex item, so the first draft let a flex parent shrink the box and the digits spilled past the border), and the forced-colors outline in `currentColor` rather than `CanvasText` (verified: a disabled Button's counter follows GrayText).

## Limitations

- Only Chromium is automated; Firefox, Safari and screen readers were not tested. `lh` needs Chromium 109, Safari 16.4 or Firefox 120.
- Digit grouping uses the runtime locale: a server and a browser with different locales would render `1,234` and `1 234` for the same value (only when `max` is raised above 999); pinning a locale is left to the integration (contract note).
- At comfortable density a single digit is wider than it is high (padding 6 px per side); the square only holds at compact and standard. A design observation for the reviewer, consequence of binding `space.content.xs`.
- Inside Button the trailing slot is `aria-hidden`: a quantity that must be announced belongs in the host's label or a live region (Button contract, kept at the contract gate).
- Live announcements on value change are left to the integration.
- The local `Counter` export in `packages/svelte/src/index.ts` and the review page are not yet listed in `documentation/index.json` and `examples/index.html` (orchestrator).
