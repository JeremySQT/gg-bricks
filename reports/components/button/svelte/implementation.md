# Button — Svelte implementation report

Component: `packages/svelte/src/components/button/` (Svelte 5.57.1, Bits UI 2.19.3 `Button.Root`). Review page: `examples/button/`; self-contained preview: `dist/previews/button.html` (`npm run build && npm run build:preview button`). Implementation approved on 2026-10-07 (status `approvals.implementation`); amended on 2026-10-13 (focus ring token binding, middle-click guard) under the audit correction batch.

## Structure

- `Button.svelte`: Bits UI `Button.Root` renders `<button type="button">`, or `<a>` when `href` is set. Anatomy: root (interaction target) › `ggb-button__container` (visible surface) › `__leading`, `__label`, `__trailing`, `__loadingIndicator`.
- `types.ts`: `ButtonProps = ButtonAsButton | ButtonAsLink`; native attributes pass through, the component owns `href`, `type`, `disabled`, `aria-busy`, `aria-disabled` and `role`; `onclick` and `onauxclick` are forwarded through the activation guard.
- `button.css`: structure, state selection (`:hover` under `(hover: hover)`, `:active`, `[data-loading]`, `[data-disabled]` in contract precedence order), cap-height centering, reduced motion, forced colors. Values only from `tokens.generated.css`.
- `contract.generated.ts`, `tokens.generated.css`: generated by `npm run build:svelte`. The generator also binds `-letterSpacing` and `-fontFeatureSettings` helpers for typography roles (the font shorthand cannot carry them).

## Contract rules and how they are met

| Rule                                                                              | Implementation                                                                                                                                                                                                                                                                  | Evidence                                                   |
| --------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------- |
| Order leading, label, trailing; label is the accessible name                      | Flex order in the DOM; slots `aria-hidden`                                                                                                                                                                                                                                      | browser: slots test (LTR and RTL order), SSR anatomy       |
| Horizontal spacing: edgeInline on the container, labelInline and slotInline       | Container `padding-inline`, label and slot `margin-inline`; no gap                                                                                                                                                                                                              | browser: slot geometry per size                            |
| Optical icon spacing (icons placed by their drawing)                              | `svg` in slots gets a negative `margin-inline` of iconSize / 8                                                                                                                                                                                                                  | browser: drawing bounds measured against the tokens        |
| One line, tight ellipsis, full accessible name                                    | The component measures the available width, renders the truncated text itself (2 px safety margin) and keeps the whole label visually hidden as the accessible name; native `text-overflow: ellipsis` without script                                                            | browser: truncation at six widths and release              |
| Cap-height centering                                                              | `text-box: trim-both cap alphabetic` on the label, `overflow: clip` with a 0.3em clip margin so descenders stay visible; line-box centering where `text-box` is unsupported                                                                                                     | browser: pixel measurement of capital letters, descenders  |
| Height = max(minHeight, content + padding); 44 px target without growing the surface | Root `min-block-size: minTarget` (the layout box is at least 44 px tall); a centered `::before` extends the target to 44 px wide without layout space; the container fills the root                                                                                             | browser: 3 sizes × 3 densities                             |
| Icon size and content color for slots                                             | `svg` in slots sized to `iconSize`; `color` inherited                                                                                                                                                                                                                           | browser: slots test                                        |
| State precedence disabled, loading, pressed, hover, default                       | CSS source order                                                                                                                                                                                                                                                                | browser: computed values, SSR                              |
| Activate only when neither disabled nor loading; never navigate then              | Native `disabled`; loading guarded in the `click` and `auxclick` handlers (`preventDefault` cancels navigation, new-tab opening and submission)                                                                                                                                | browser: loading and disabled tests, middle and Ctrl click |
| href → link, same appearance                                                      | Bits UI renders `<a>`; disabled removes `href`, sets `aria-disabled` and `tabindex=-1`                                                                                                                                                                                          | SSR, browser                                               |
| Disabled leaves focus order; loading stays focusable and busy                     | Native `disabled`; loading uses `aria-busy` + `aria-disabled` without native `disabled`                                                                                                                                                                                         | browser: focus kept, geometry unchanged                    |
| Loading indicator centered, content hidden but laid out                           | Absolutely positioned indicator; content `opacity: 0` (stays in the accessibility tree)                                                                                                                                                                                         | browser: bounding box identical before/after               |
| Border only for outline, no size change                                           | Inset `box-shadow`                                                                                                                                                                                                                                                              | browser: computed box-shadow per appearance                |
| Focus indicator, concentric corners                                               | `:focus-visible` outline on the container, `focusWidth`/`focusColor`/`focusOffset`; the browser draws the outline concentric with the radius, the value `focusRadius` records                                                                                                  | browser: focus state in 4 contexts                         |
| Transitions, reduced motion                                                       | `background-color, color, box-shadow` over `motion.duration.fast` + `easing.standard`; none under reduced motion; spinner slowed to 2.4 s                                                                                                                                      | browser: motion test                                       |
| Forced colors                                                                     | Transparent 1 px outline becomes visible; `Highlight` focus; `GrayText` when disabled                                                                                                                                                                                           | browser: forced-colors test + screenshot                   |

## Limitations

- Only Chromium is automated; Firefox, Safari and screen readers were not tested. Firefox has no `text-box` support yet and centers the line box instead of the capital letters.
- Slot content cannot be restricted to Icon, Counter or Shortcut by the type system; it is a documented rule. Slot content is hidden from assistive technology, so information it carries (a counter value) must also be in the label or described by the application.
- Since 2026-10-14 the review page uses the Icon, Counter and Shortcut components (wave 1) with Phosphor review glyphs; before that it used local fixtures. The automated audit tolerates the documented contrast exception of the attenuated plain Shortcut inside buttons (user decision at the wave 1 implementation gate).
- A loading link keeps its `href` (so it stays focusable) and cancels activation, middle click and modified clicks in script; the context menu can still open the destination, and without JavaScript it would navigate.
- The truncation algorithm slices the label on UTF-16 code units; a label ending in an emoji or a combining sequence may be cut inside it at some widths (not reproduced, noted at the audit of 2026-10-13).
