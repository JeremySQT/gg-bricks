# Change record — Icon glyph source in Figma

- Request and scope: during the wave 1 implementation review of IconButton, Link and Badge (2026-10-19), the user noticed that the Phosphor library was not really available in Figma ("la librairie Phosphor n'était pas vraiment importée sur figma") and chose a local import of the full regular set (option A), on a page of its own, `assets/phosphor`, so that designers do not mistake it for the Icon component, with a notes frame recording the import date, the version and the guidelines. Scope: the Figma glyph source of the Icon component; no contract, token or code change.
- Starting source/output references: Figma parity approved on 2026-10-14 (figma-spec.md digest `928a1318…`, ledger digest `9c0af037…`); Glyph instance-swap property defaulting to `_Fixture/Icon` Name=plus (42:7), preferred values the `_Fixture/Icon` set (74:2, five glyphs, Utilities page).
- Affected components, dependencies and contexts: Icon (component set 149:20, specification 152:7) and its hosts in the file: the Button masters and specification (48:1586, 126:1904). Counter, Shortcut, Getting started, Foundations and Cover hold no icon instance.
- Compatibility and reason: compatible. Same component set, variants, property key and bindings; only the components the Glyph property points to change. The five replacement glyphs have vector paths byte-identical to the fixtures', so no instance changes its rendering.
- Source decisions and target-only adaptations: decision Icons in `authoring/decisions.md` amended (local import instead of the community library, glyphs reached only through Icon or an icon slot); page model in `authoring/figma.md` gains `assets/<name>` pages. Figma-only change.
- Changed artifacts: Figma page `assets/phosphor` (199:2) with 1,512 components `phosphor/<name>` and the notes frame 201:2; Icon Glyph default `phosphor/plus` (200:4367), preferred values cleared so that the swap menu lists every local glyph; 90 instances swapped (77 on content/icon, 13 on actions/button); `_Fixture/Icon` (74:2) and its frame 42:2 deleted; two sentences of the Icon specification and the Icon set description rewritten. Repository: `figma-spec.md` (mapping and justified difference 3), `reports/components/icon/figma/ledger.json`, `reports/components/icon/figma/specification.png`, `reports/assets/phosphor/` (ledger and notes screenshot), adapter scripts `phosphor-components.plugin.js`, `phosphor-spec.plugin.js`, and the glyph IDs in `icon-spec.plugin.js` and `button-spec.plugin.js`. Button: `figma-spec.md` justified difference 10.
- Approvals retained or reopened, with provenance: Icon and Button Figma parity approvals re-recorded with the new digests on the user's request of 2026-10-19 (session https://claude.ai/code/session_01KQ5qDJziTR2xrfyLuKzfiU: "Je penche pour l'option A", then "Je suis d'accord pour faire sur une page voisine, mais peut-être plus sous assets/Phosphor ou library/phosphor, à voir ce que tu me recommandes […] il faudrait aussi ajouter une petite spec sur la page de la librairie"); `parity.json` unchanged (its records measure the box, the drawing size and inset and the fill binding, which the identical vectors keep). Contract, implementation and documentation approvals retained.
- Checks performed and evidence: 1,512 components counted on the page, one per SVG of `@phosphor-icons/core` 2.1.1 `assets/regular`; vector paths of plus, arrow-right, trash, download-simple and check compared with the fixtures' (identical); after the swap no instance in the file references a deleted component; screenshots of the Icon specification (152:7) and the Button specification (126:1904) inspected, no visual change besides the two rewritten sentences; `npm run verify`.
- Remaining limitations: the library is not published (publication needs explicit authorization); other Phosphor weights are not imported; a later Phosphor version replaces the vectors of the existing components in place, keeping components and names (procedure in the notes frame); `phosphor-components.plugin.js` creates components from new uploads and needs an extra step for in-place replacement.
