# Authoring instructions

The kit contains two repository-scoped skills:

- **ds-component-workflow:** route creation, modification, audit and delivery through the four procedures; enforce the agreed review gates.
- **ds-component-contract:** scope and draft the compact shared contract.

Phase-specific guidance is implemented in [the authoring playbook](authoring-playbook.md): contract/tokens, Figma, Svelte, documentation and validation. Keep substantive instructions in one place. Separate phase skills can be extracted later if agent discovery or repeated usage warrants them; do not maintain duplicate procedures now.

Figma reconciliation and foundation changes belong to Modify. Incompatible evolution is its migration branch. There is no separate interruption-recovery workflow.

These skills are repo-owned files supplied with shared references two levels above their directories; they are not globally installed personal skills. Preserve or update relative paths when moving the kit. Specialized tool skills still apply to the relevant tools.

Example: "Read AGENTS.md and follow the component workflow to define a DatePicker contract. Use Button as the reference format."

Consumer packages contain use guidance and an economical component index, not these fabrication procedures.
