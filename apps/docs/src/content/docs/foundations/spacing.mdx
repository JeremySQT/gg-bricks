Spacing comes in three families. **Layout** spacing separates regions of a page, **content** spacing separates elements inside a region, and **control** spacing shapes interactive controls. Spacing and control heights follow the density selected in the header; icon sizes and the interaction target do not.

Visible dimensions are distinct from interaction targets: a small control may be 28 px tall and still offer a 44 × 44 CSS px target.
