Interface text is set in Inter in every brand, code in IBM Plex Mono. Each role is a composite token: family, weight, size, line height and letter spacing. In CSS a role is a `font` shorthand (`font: var(--ggb-typography-body-md)`) with its letter spacing beside it (`letter-spacing: var(--ggb-typography-body-md-letterSpacing)`); `-fontSize` and `-lineHeight` are also exposed.

Font sizes do not change with density: a compact interface is tighter, not smaller.
