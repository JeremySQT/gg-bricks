  <Card title="Sources first" icon="document">

  </Card>
  <Card title="Three independent axes" icon="setting">
    Brand, appearance and density are attributes on one ancestor. A brand overrides a handful of aliases; light, dark
    and three densities come with every brand.
  </Card>
  <Card title="Copyable components" icon="puzzle">
    Every component folder is self-contained: copy it next to `tokens.css` and Bits UI, or install `@ggbrick/svelte`.
  </Card>
  <Card title="Evidence, not claims" icon="approve-check">
    Contrast in 18 contexts, accessibility checks in a real browser and Figma parity reports are recorded for every
    component and summarized on its page.
  </Card>
